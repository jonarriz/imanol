# Oye Imanol

Web de servicios (desarrollo web, hosting y servidores, automatizaciones e IA) publicada con GitHub Pages.

## Configurar
Edita el bloque `CONFIG` al final de `index.html`:
- `email`: email de contacto
- `whatsapp`: número con prefijo, sin + ni espacios (ej. 34600111222)
- `formspree`: ID del formulario de https://formspree.io (si se deja vacío, el formulario abre el correo del visitante)

## Publicar
Settings → Pages → Source: *Deploy from a branch* → `main` / `(root)`.
